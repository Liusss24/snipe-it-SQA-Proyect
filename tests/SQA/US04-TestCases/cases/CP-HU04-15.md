## Steps

3. Abrir el flujo usando teclado (Enter o Space).
4. Verificar el orden del foco entre los elementos del formulario.
5. Seleccionar un usuario con teclado, si la interfaz lo permite.
6. Confirmar el checkout.
7. Revisar la legibilidad del mensaje de éxito, alineación de campos y claridad de etiquetas.

## Actual result

Ejecutado el 2026-05-30 con asistencia del script `run_manual_cp_hu04_15.py`
(Chromium headed, 1920×1080) y revisión visual de las capturas.

- **Orden de foco (Tab):** lógico y completo. Secuencia registrada:
  1. Categoría (link "Misc Software")
  2. `checkout_to_type` (toggle User/Asset)
  3. Select "Select a User" (campo destino)
  4. Botón "New"
  5. Textarea "Checkout Note"
  6. "Cancel"
  7. Select "Return to all Licenses" (redirect option)
  8. Botón "Checkout" (submit)
  Tras el submit el foco continúa por el navbar y el footer, sin perderse.
- **Controles visibles y entendibles:** sí. Formulario alineado, con etiquetas
  a la izquierda (Asset Name, Category, Product Key, Checkout to, User,
  Checkout Note) y el botón de confirmación verde claramente identificable.
- **Etiquetas:** claras. "Checkout to", "User" y el botón "Checkout" son
  inequívocos. El encabezado muestra "LIC-HU04-15 (3 seats available)".
- **Mensaje de confirmación:** legible y no cortado:
  "Success: The license was checked out successfully" (banner verde a ancho
  completo).
- **Errores visuales:** ninguno relevante observado.

## Observations
