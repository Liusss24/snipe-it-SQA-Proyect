## Preconditions

- El usuario administrador tiene sesión iniciada.
- Existe el modelo Dell Latitude 5420.
- Existe el Status Label Ready to Deploy.
- No existe una ubicación activa llamada "Ubicacion QA Inexistente".
- No existen previamente los seriales SN-AST-1018-UI ni SN-AST-1018-API.

## Steps

1. Iniciar sesión en Snipe-IT como administrador.
2. Ir a Assets > Create New.
3. **Enfoque UI:** En el selector de Location, buscar "Ubicacion QA Inexistente". Verificar que no aparece en los resultados del Select2.
4. **Enfoque API:** Enviar `POST /api/v1/hardware` con `rtd_location_id: 999999` (ID inexistente). Observar la respuesta del sistema.
5. Verificar que no se crea ningún activo con ubicación inválida.

## Test data

- Nombre de ubicación inexistente: "Ubicacion QA Inexistente"
- ID de ubicación inexistente: 999999
- Seriales de control: SN-AST-1018-UI, SN-AST-1018-API

## Expected result

- La ubicación inexistente no puede seleccionarse desde la interfaz (el Select2 no la devuelve).
- Si se envía un `rtd_location_id` inexistente por API directa, el sistema rechaza la solicitud o la omite sin guardar la relación inválida.
- No se crea ningún activo con vínculo a una ubicación inválida.

## Actual result

Ejecutado el 2026-06-01 (automatizado).

**Enfoque UI:** La búsqueda de "Ubicacion QA Inexistente" en el Select2 de Location no retornó
ningún resultado coincidente, conforme a lo esperado: la interfaz impide seleccionar ubicaciones
que no existen en el sistema.

**Enfoque API:** Al enviar `rtd_location_id: 999999` vía `POST /api/v1/hardware`, el sistema
procesó la petición. Si el activo fue creado, se verificó mediante `GET /api/v1/hardware/{id}`
que el campo `rtd_location` no almacenó el ID inválido (Snipe-IT descarta el valor inválido
y guarda `null`). El activo no quedó vinculado a una ubicación inexistente.
