4. Ingresar el mismo Asset Tag `AST-HU01-DUP` (ya existente).
5. Completar los demás campos con datos válidos: nombre "Laptop tag duplicado QA", modelo, serial único, status, location.

7. Verificar que el sistema muestra error de duplicidad y no crea el activo.
