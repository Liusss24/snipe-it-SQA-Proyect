## Metadata

- **ID:** CP-HU01-20
- **Title:** Validación de sanitización del campo Asset Name ante entrada tipo script
- **Module:** Assets – Create New
- **US:** HU01
- **Type:** Sistema
- **Technique:** Prueba negativa / Validación de seguridad (XSS)
- **Execution:** Automatizada – Python 3.14 + pytest + Playwright
- **Priority:** Medium
- **Hardware:** Laptop Lenovo Ideapad 3
- **OS:** Windows 11
- **Browser:** Chrome (Chromium vía Playwright) – 1920×1080
- **Assigned to:** María Paula Castillo Chinchilla

## Preconditions

- El usuario administrador tiene sesión iniciada.
- Existe el modelo Dell Latitude 5420.
- Existe la ubicación Oficina Central.
- Existe el Status Label Ready to Deploy.
- No existe previamente el serial SN-AST-1020.

## Steps

1. Iniciar sesión en Snipe-IT como administrador.
2. Ir a Assets > Create New.
3. En el campo Asset Name ingresar: `<script>alert("QA-PRUEBA")</script>`.
4. Completar los demás campos con datos válidos: Model Dell Latitude 5420, Serial SN-AST-1020, Location Oficina Central, Status Ready to Deploy.
5. Presionar Save.
6. Observar si aparece algún `alert()` del navegador.
7. Si el sistema guardó el activo, navegar a su vista de detalle.
8. Verificar que el texto aparece como texto plano escapado, no ejecutado.
9. Ir al listado de Assets y verificar que tampoco se ejecuta el script ahí.

## Test data

- **Asset Name (payload XSS):** `<script>alert("QA-PRUEBA")</script>`
- Serial: SN-AST-1020 | Model: Dell Latitude 5420 | Location: Oficina Central | Status: Ready to Deploy

## Expected result

- El sistema no ejecuta el script en ningún momento (formulario, detalle, listado).
- No aparece ningún `alert("QA-PRUEBA")` en el navegador.
- Si el sistema guarda el activo, el valor del campo se muestra escapado como texto plano (e.g. `&lt;script&gt;...`).
- La interfaz no interpreta el contenido como HTML o JavaScript ejecutable.

## Actual result

Ejecutado el 2026-06-01 (automatizado). El sistema aceptó el payload XSS en el campo Asset Name
y creó el activo mostrando "Asset created successfully". En ningún momento se disparó un `alert()`
del navegador: ni durante el submit, ni al cargar la vista de detalle, ni al navegar al listado
de Assets.

El listener de diálogos de Playwright (`page.on("dialog", ...)`) registró cero eventos durante
toda la ejecución. El contenido HTML del detalle mostró el payload correctamente escapado
(Snipe-IT/Laravel Blade aplica `htmlspecialchars` automáticamente en las vistas), sin que el
navegador lo interpretara como código ejecutable. El sistema superó la validación de seguridad XSS.
