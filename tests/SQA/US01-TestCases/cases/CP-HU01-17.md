## Preconditions

- El usuario administrador tiene sesión iniciada.
- Existe el modelo Dell Latitude 5420.
- Existe el Status Label Ready to Deploy.
- No existe previamente el serial SN-AST-1017.

## Steps

1. Iniciar sesión en Snipe-IT como administrador.
2. Ir a Assets > Create New.
3. Completar el formulario con: Asset Tag, Asset Name "Laptop sin ubicacion QA", Model Dell Latitude 5420, Serial SN-AST-1017, Status Label Ready to Deploy.
4. Dejar vacío el campo Default Location / Location (no seleccionar ninguna ubicación).
5. Presionar Save.
6. Observar la validación mostrada por el sistema.

## Test data

- Asset Name: Laptop sin ubicacion QA
- Serial: SN-AST-1017 | Model: Dell Latitude 5420 | Status: Ready to Deploy
- **Location: vacía (omitida)**

## Expected result

- El sistema no guarda el activo.
- El campo Location se marca como requerido o inválido.
- Se muestra un mensaje de validación relacionado con ubicación obligatoria.
- No aparece "Asset created successfully".

## Actual result

Ejecutado el 2026-06-01 (automatizado). **El sistema permitió crear el activo sin ubicación**
y mostró "Asset created successfully". El campo Default Location no es obligatorio en
Snipe-IT v8: el activo quedó registrado con `rtd_location_id = null`. El comportamiento
del sistema contradice lo especificado en el Plan de Pruebas.

Se documenta como defecto **DEF-US01-17**. El caso complementario **CP-HU01-17b**
(función `test_cp_hu01_17b_sistema_permite_crear_sin_location`) valida el comportamiento
real y queda en verde.
