# CP-HU01-02

## Metadata

- **ID:** CP-HU01-02
- **Title:** Creación exitosa de activo con Asset Name de 255 caracteres
- **Module:** Assets – Create New
- **US:** HU01
- **Type:** Sistema
- **Technique:** Análisis de valores límite (límite superior válido)
- **Execution:** Automatizada – Python 3.12 + pytest + Playwright
- **Priority:** Medium
- **Hardware:** Laptop Lenovo ThinkBook
- **OS:** Windows 10
- **Browser:** Zen Browser (Chromium) – 1920×1080
- **Assigned to:** Aarón Líos Cubillo

## Preconditions

- El usuario tiene sesión iniciada y permisos para crear activos.
- Existe el modelo Dell Latitude 5420, asociado a la categoría Laptops.
- Existe la ubicación Oficina Central y el Status Label Ready to Deploy.
- No existe previamente el serial SN-AST-1002.
- Se dispone de una cadena válida de exactamente 255 caracteres.

## Steps

1. Iniciar sesión en Snipe-IT.
2. Entrar a Assets > Create New.
3. En Asset Name, ingresar una cadena de exactamente 255 caracteres.
4. Model = Dell Latitude 5420.
5. Serial = SN-AST-1002.
6. Location = Oficina Central.
7. Status Label = Ready to Deploy.
8. Ingresar Asset Tag único.
9. Presionar Save.

## Test data

- Asset Name: cadena de 255 caracteres ("A" × 255)
- Serial: SN-AST-1002 | Model: Dell Latitude 5420 | Status: Ready to Deploy

## Expected result

- El sistema acepta el valor límite de 255 caracteres.
- El activo se guarda y se muestra "Asset created successfully".
- No se muestran errores de longitud.

## Actual result

Ejecutado el 2026-05-30 (automatizado). **El sistema NO acepta 255 caracteres.**
El campo Asset Name tiene `maxlength="191"` (columna `assets.name varchar(191)`),
por lo que impide ingresar más de 191 caracteres y almacena el valor truncado a
191. Resultado de la automatización:
`AssertionError: El nombre almacenado no tiene 255 caracteres: 191`.

Se documenta como defecto **DEF-US01-01** (discrepancia entre el Plan de Pruebas,
que asume 255, y el límite real del sistema, 191). El caso complementario
**CP-HU01-02b** valida el borde real de 191 caracteres y queda en verde.
