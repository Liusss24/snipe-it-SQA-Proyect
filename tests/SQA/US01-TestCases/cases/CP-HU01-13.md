## Preconditions

- El usuario tiene sesión iniciada y permisos para crear activos.
- Existe el modelo Dell Latitude 5420 asociado a la categoría QA Laptops.
- Existe la ubicación Oficina Central.
- Existe el Status Label Ready to Deploy.

## Steps

1. Iniciar sesión como administrador.
2. Ir a Assets > Create New.
3. Ingresar un Asset Tag único válido.
4. En el campo Asset Name, ingresar exactamente **256 caracteres** (cadena "A" × 256, supera límite de 255).
5. Completar los demás campos: modelo, serial, status, location válidos.
6. Hacer clic en **Save**.
7. Verificar si el sistema rechaza el valor con error de longitud o lo acepta (defecto).

## Test data

- Asset Name: 256 'A' (supera el límite) | Asset Tag: único | Model, Status, Serial: válidos

## Expected result

El sistema rechaza el valor de 256 caracteres. Muestra error de longitud máxima. El activo no se guarda.

## Actual result

Ejecutado el 2026-06-04 (automatizado). **DEF-US01-01**: Al enviar un Asset Name de 256 caracteres ('A' × 256) omitiendo el `maxlength=191` del HTML (Playwright bypasea el atributo), el sistema mostró el banner verde "Asset with tag AST-HU01-1013-XXXXXX was created successfully." El activo fue creado con el nombre truncado a 191 caracteres sin emitir ningún mensaje de error. El test queda `xfail(strict=True)`.
