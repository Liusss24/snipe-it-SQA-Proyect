## Preconditions

- El usuario tiene sesión iniciada y permisos para crear activos.
- Ya existe un activo registrado con el serial SN-001234.
- Existe el modelo Dell Latitude 5420 y la ubicación Oficina Central.
- **El ajuste `unique_serial` de Snipe-IT está activado.** Por defecto Snipe-IT
  NO obliga seriales únicos; el fixture `unique_serial_enabled` lo activa
  durante la prueba y restaura el valor original al finalizar.

## Steps

1. Iniciar sesión en Snipe-IT.
2. Ir a Assets > Create New.
3. Completar con datos válidos: Asset Name = "Laptop duplicada QA", Model =
   Dell Latitude 5420, Serial = SN-001234, Location = Oficina Central,
   Status = Ready to Deploy.
4. Ingresar Asset Tag único.
5. Presionar Save.
6. Observar la validación mostrada.

## Test data

- Serial duplicado: SN-001234 (ya existente)

## Expected result

- El sistema no guarda el nuevo activo.
- Se muestra la validación de unicidad del serial
  (UI: "The serial has already been taken." / API: "The serial must be unique.").
- No aparece "Asset created successfully".
- No queda un segundo activo con el mismo serial.

## Actual result

Ejecutado el 2026-05-30 (automatizado) con el ajuste `unique_serial` activado
por el fixture. El sistema rechazó la creación del activo con serial duplicado
y mostró la validación de unicidad ("The serial must be unique." / en UI
"The serial has already been taken."). No se creó un segundo activo con el
serial SN-001234 (verificado vía API). El ajuste fue restaurado a su valor
original al finalizar.
