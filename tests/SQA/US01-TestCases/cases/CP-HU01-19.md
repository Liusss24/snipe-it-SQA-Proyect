## Preconditions

- El usuario administrador tiene sesión iniciada.
- Existe el modelo Dell Latitude 5420, asociado a la categoría Laptops.
- Existe la ubicación Oficina Central.
- Existe el Status Label Ready to Deploy.
- No existe previamente el serial SN-AST-1019.

## Steps

1. Iniciar sesión en Snipe-IT como administrador.
2. Ir a Assets > Create New.
3. Crear un activo con: Asset Name "Laptop historial QA", Model Dell Latitude 5420, Serial SN-AST-1019, Location Oficina Central, Status Ready to Deploy.
4. Presionar Save. Confirmar el mensaje "Asset created successfully".
5. Obtener el ID del activo creado vía `GET /api/v1/hardware?search=SN-AST-1019`.
6. Consultar el historial: `GET /api/v1/reports/activity?item_type=asset&item_id={id}&limit=50`.
7. Verificar que existe una entrada de tipo `create new` en el historial.
8. Verificar que el log está asociado al ID del activo correcto.

## Test data

- Asset Name: Laptop historial QA

## Expected result

- El activo se crea correctamente y se muestra "Asset created successfully".
- El historial del activo (`/api/v1/reports/activity?item_type=asset&item_id={id}`) contiene al menos una entrada con `action_type = "create new"`.
- El registro está asociado al activo correcto.

## Actual result

Ejecutado el 2026-06-01 (automatizado). El activo se creó correctamente. La consulta al endpoint
`GET /api/v1/reports/activity?item_type=asset&item_id={id}&limit=50` retornó entradas del historial
con `action_type = "create new"` asociadas al activo correcto.

**Hallazgo de implementación:** el endpoint documentado en el plan (`/api/v1/hardware/{id}/activity`)
devuelve **404** en Snipe-IT v8 — no existe. El endpoint correcto para consultar la actividad de
un activo es `/api/v1/reports/activity` filtrado por `item_type=asset&item_id={id}`. El helper
`get_asset_activity()` en `conftest.py` fue corregido para usar el endpoint real.
