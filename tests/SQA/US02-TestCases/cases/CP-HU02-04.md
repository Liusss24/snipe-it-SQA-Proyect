- El sistema tiene habilitado el registro de acciones (action_logs).

## Steps

1. Crear activo y usuario vía API (fixtures).
2. Ejecutar checkout del activo hacia el usuario (`POST /api/v1/hardware/{id}/checkout`).
3. Consultar la tabla `action_logs` de la BD (vía `docker exec mariadb`) filtrando por `item_id={assetId}` y `action_type='checkout'`.
4. Verificar que existe al menos un registro.
5. Verificar que el campo `target_id` corresponde al usuario que recibió el activo.
6. Fallback: si Docker/BD no es accesible, verificar que `last_checkout` no es nulo vía API.
