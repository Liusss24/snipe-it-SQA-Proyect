## Preconditions

- Existe un usuario autenticado con permisos de checkout.
- Existe un activo en estado **Deployed** (ya asignado a otro usuario).

## Steps

1. Iniciar sesión en Snipe-IT como administrador.
2. Ir al listado de activos (Hardware > Assets).
3. Abrir el detalle de un activo con estado **Deployed**.
4. Observar si la opción **Checkout** está visible y/o habilitada.
5. Si la interfaz lo muestra, intentar iniciar un nuevo checkout.
6. Observar la respuesta del sistema.

## Test data

- Activo preexistente en estado Deployed (asignado a un usuario).

## Expected result

- La opción **Checkout** no se muestra o aparece deshabilitada para activos en Deployed.
- Si se intenta forzar la acción, el sistema muestra: `"This asset is already checked out"`.
- No se crea una nueva asignación.

## Actual result

- La opción **Checkout** no se muestra o aparece deshabilitada para activos en Deployed.
- En lugar de la opción **Checkout**, se muestra la opción **Checkin** para liberar el activo.
