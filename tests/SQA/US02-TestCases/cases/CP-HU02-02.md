## Preconditions

- Existe un activo con estado Ready to Deploy.
- Existe un usuario válido como destinatario.
- El usuario autenticado tiene permisos para realizar checkout.

## Steps

1. Consultar el estado del activo antes del checkout (`GET /api/v1/hardware/{id}`).
2. Verificar que `status_label.status_meta` sea `"deployable"`.
3. Ejecutar checkout del activo hacia un usuario válido (`POST /api/v1/hardware/{id}/checkout`).
4. Consultar nuevamente el estado del activo.
5. Verificar que `status_label.status_meta` sea `"deployed"`.
