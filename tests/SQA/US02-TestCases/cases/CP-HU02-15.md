## Preconditions

- Existe un usuario autenticado con permisos de checkout.
- Existe un activo con estado Ready to Deploy no asignado.
- Existen dos usuarios válidos como destinatarios (usuario A y usuario B).

## Steps

1. Crear activo y dos usuarios vía API (fixtures).
2. Ejecutar primer checkout: activo → usuario A (`POST /api/v1/hardware/{id}/checkout`).
3. Verificar que el primer checkout fue exitoso.
4. Ejecutar inmediatamente segundo checkout: activo → usuario B.
5. Consultar estado final del activo.
6. Consultar asignación final del activo.
7. Verificar que usuario B no tiene el activo asignado.
